# Urdu Voice

Urdu voiceover generator using Google Gemini text-to-speech (built-in voices).
Runs fully in the browser — bring your own Gemini API key from Google AI Studio.
The key is sent only to Google and is stored on your device only if you tick "remember".

Open: https://myasir66.github.io/urdu-voice/

## Your own voice (Colab, free T4 GPU)

Clone your own voice with OmniVoice and make Urdu voiceovers. Only clone your own voice.

- App (Gradio, public link, voices saved in Google Drive): [Open in Colab](https://colab.research.google.com/github/myasir66/urdu-voice/blob/main/colab/urdu_voice_app.ipynb)
- Quick test: [Open in Colab](https://colab.research.google.com/github/myasir66/urdu-voice/blob/main/colab/urdu_voice_clone_test.ipynb)
